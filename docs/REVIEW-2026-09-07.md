# Public repository review — 2026-09-07

Reviewed the CLI and companion skills for correctness, data loss, security, portability,
packaging and documentation. Findings were reproduced with synthetic projects or isolated
fault injection, patched, and independently reviewed. No production CapCut project was edited.

## Fixed

- Blocked prototype traversal in patches and unset paths; constrained managed draft,
  timeline and snapshot paths; rejected symlinked destinations and invalid snapshot checksums.
- Made snapshot restore dry runs read-only. Failed project removal now restores the draft
  when registry publication fails; failed file staging closes descriptors and cleans up.
- Preserved earlier imported media across repeated source-file replacements and filename
  collisions. New projects retain correct source provenance and discard inherited motion,
  transitions and speed changes. Multi-match media replacement now updates every match.
- Rejected malformed draft structures, invalid times and unmatched mask selectors. Unknown
  CLI options fail before editing; `doctor` exits unsuccessfully when it finds errors.
- Preserved audible Arabic speech instead of filtering it by credit-related words. Corrected
  multichannel/PCM energy indexing, final audio bins and transcript cache provenance.
- Corrected preview speed and mixed-resolution concatenation, QA aspect ratios and measured
  frame timestamps. Preview publication uses securely created temporary files; frame metadata
  stays within the image-cache budget.
- Prevented review output publication from replacing a CapCut project, its source media,
  symlink targets or unrelated existing directories.
- Protected talking-head and layout helper lanes from pacing, used exact source coverage,
  honored explicit speed choices and `polish --no-sfx`, and handled truncated WebP headers.
  Signature effects now skip and report unavailable machine-local SFX.
- Kept music timeouts active while downloading response bodies and checked CapCut's running
  state before starting a chargeable generation request.
- Prevented forged review-comment markers from suppressing inline findings and corrected
  diff line counting for increment/decrement operators. Local quality gates now respect tool
  failure statuses instead of trusting reassuring output.
- Removed thirteen superseded skills scripts that bypassed transactions or contained stale
  editing/indexing logic. Added a migration map, corrected document/mirror and ROI guidance,
  preserved approval gates, and strengthened command validation and installation instructions.

## Security checks

- Gitleaks scanned all locally available Git history in both repositories with redacted
  reporting. No credentials were detected.
- Zizmor's offline workflow scan found no findings in either repository.
- Bandit findings were limited to low-severity subprocess imports/calls and PATH-based
  executable lookup. These calls use argument arrays; installed tools and PATH are trusted
  local configuration. No medium- or high-severity findings were reported.
- The old installed Pillow version had known advisories. The dependency floor is now
  `Pillow >=12.3.0`, covering its published [decoder security fixes](https://pillow.readthedocs.io/en/stable/releasenotes/12.3.0.html).
  Fresh runtime dependencies and the resolved optional Whisper dependency set passed
  `pip-audit` without known advisories. Optional Whisper packages and model weights were
  not installed by that audit.
- GitHub secret scanning, push protection and private vulnerability reporting were enabled
  and verified for both public repositories. Added Python dependency update monitoring.

## Validation and limits

Local validation passed `./scripts/check.sh --strict`: 360 tests with no skips, Python 3.11
self-tests and compilation, Ruff, Vulture, ShellCheck and macOS Vision OCR. A real synthetic
media round trip separately verified project creation, snapshot creation, volume dry-run
and apply, restore dry-run and apply, and a clean doctor result. The skills validator passed
with all 13 negative regressions caught. The CLI contract was synchronized, and the package
inspection contained 49 intended files with no environment, cache or credential files.
Hosted CI must pass for the pushed commits before this review is considered complete.
Source distribution remains through GitHub; npm publishing remains disabled.

This review does not prove every CapCut version or native effect renders identically.
Paid music generation and real model inference were not exercised. A fresh third-party
Mac setup remains tracked by [CLI issue 12](https://github.com/RoXsaita/capcut-editor-cli/issues/12);
unfinished event compilation and unguided screen matching remain tracked by
[skills issue 3](https://github.com/RoXsaita/capcut-skills/issues/3). These issues remain open.
Security scans describe the versions and repository state reviewed on this date.
